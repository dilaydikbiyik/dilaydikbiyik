### 🚀 Selected Work

| Project | What it does | Built with |
| --- | --- | --- |
| [**keyword-extractor**](https://github.com/dilaydikbiyik/keyword-extractor) · [research record](https://dilaydikbiyik.github.io/keyword-extractor) | Zero-shot NACE classification of German trade-register texts. Rewriting the taxonomy's class descriptions as real definitions is worth +26.8 points Top-1 — 81.6% Top-3 on 299 corpus-sampled documents. Every number is regenerated by `make reproduce` and checked by CI; three label-free studies were preregistered before they were measured | Python · Sentence-Transformers · scikit-learn |
| [**Lumos**](https://github.com/dilaydikbiyik/lumos) ([live](https://lumos-sooty.vercel.app)) | An assistant that walks first-time investors through risk profiling and portfolio building, backed by a free-tier LLM chain (Gemini, with Groq and OpenRouter as automatic fallbacks) instead of being locked to one provider. The LLM never does the math — deterministic engines do, and that boundary is enforced by tests | FastAPI · React · Gemini/Groq/OpenRouter |
| **unshackled-llm-bridge** *(private, in testing)* | Browser extension that moves a conversation — with its uploaded files and your own context — between ChatGPT, Claude and Gemini, entirely locally, with no backend and no telemetry. Six layers whose import boundaries are enforced by the linter rather than by review | TypeScript · Chrome Extensions · Playwright |
| [**product-genai-pipeline**](https://github.com/dilaydikbiyik/product-genai-pipeline) | Turns bare product titles into descriptions (T5), predicted categories, and clusters of similar listings | Python · Transformers |
