### 🔬 Research

#### [What a Class Description Buys](https://dilaydikbiyik.github.io/keyword-extractor) · [`keyword-extractor`](https://github.com/dilaydikbiyik/keyword-extractor)
*Zero-shot NACE classification of German trade-register texts — Python · Sentence-Transformers · scikit-learn*

A zero-shot classifier is handed the names of its classes and nothing else. Rewriting those names into real definitions is usually treated as prompt-fiddling; it isn't. What a description buys is **alignment with the vocabulary of the documents it must attract**, and how much that is worth can be measured before accuracy is.

- **+26.8 points Top-1** from rewriting the class descriptions as definitions — 81.6% Top-3 on 299 corpus-sampled documents, against 46.8% for an oracle majority-class floor
- Controlled three ways: it is not the language (a literal German rendering of the same content is 2.3 points *worse*), not the encoder, and not one corpus — on 20 Newsgroups the same work buys nothing, and that exception is the point
- **Three label-free studies preregistered** — predictions committed to git before any accuracy existed; 12 of 15 held
- A headline number of my own was **retracted**: 80.0% measured on hand-written examples became 52.5% on real records. The research record above lists every claim the project made and what became of it, including two of its own hypotheses that the evidence destroyed
- Every figure regenerated by `make reproduce`; 46 comparisons Holm-corrected; 106 tests and CI
